Как запустить приложение

1. Открыть Git Bash.
2. Перейти в папку проекта:
   cd /g/PythonProjects/irnity/course_db_hr

3. Активировать виртуальное окружение:
   .venv/Scripts/activate

4. Запустить приложение:
   python main.py

5. Для входа использовать одну из демо-учетных записей из файла demo_accounts.txt.
