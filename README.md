# Курсовой проект по дисциплине «Базы данных»

## Тема
Отдел кадров

## Описание проекта
Приложение предназначено для работы с базой данных отдела кадров.
Система позволяет:

- вести список отделов;
- вести список сотрудников;
- вести список детей сотрудников;
- формировать отчеты по данным базы;
- выполнять вход в систему под разными ролями пользователей.

## Используемые технологии

- Python
- Tkinter
- MySQL
- mysql-connector-python
- python-dotenv

## Структура базы данных

### Таблица departments
Содержит информацию об отделах:
- номер отдела;
- название отдела.

### Таблица employees
Содержит информацию о сотрудниках:
- табельный номер;
- фамилия;
- имя;
- отчество;
- стаж работы;
- пол;
- номер отдела.

### Таблица children
Содержит информацию о детях сотрудников:
- номер свидетельства о рождении;
- имя ребенка;
- год рождения;
- пол;
- табельный номер сотрудника.

### Таблица users
Содержит данные для авторизации:
- логин;
- пароль;
- роль.

## Возможности приложения

### Для специалиста отдела кадров
- просмотр, добавление, изменение и удаление отделов;
- просмотр, добавление, изменение и удаление сотрудников;
- просмотр, добавление, изменение и удаление записей о детях;
- формирование отчетов.

### Для руководителя отдела кадров
- просмотр отчетов.

## Реализованные отчеты

1. Информация о детях сотрудников определенного отдела.
2. Сгруппированный список всей базы данных.

## Как запустить проект

1. Открыть Git Bash.
2. Перейти в папку проекта
```bash
cd /g/PythonProjects/irnity/course_db_hr
```
3. Активировать виртуальное окружение
```bash
.venv/Scripts/activate
```
4. Запустить приложение
```bash
python main.py
```
